Mhomho app: screen styles

Static reference for the creator, brand and admin screens. Copy the tokens and components into the real app so every screen keeps this look.

  • The orange to red gradient is for primary buttons, progress fills and one key number per screen. Nowhere else.
  • Cards: 14px radius, thin border, no shadows. Buttons: 10px radius, 48px tall minimum.
  • Montserrat 400, 600 and 800 only. Muted grey for secondary text.
  • Status colours: green verified, amber submitted, red rejected or flagged.
  • Mobile first. Creators get the bottom tab bar. Brands never see creator contact details or Mhomho's cut.
